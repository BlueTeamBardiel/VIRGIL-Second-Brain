# 802.1Q Trunking

## What it is

In **Pac-Man**, the four ghosts — Blinky, Pinky, Inky, Clyde — all share the same maze corridors, but you always know which ghost is which because each one wears a different color. Same hallway, distinct identities. That's exactly what 802.1Q does — it paints a color onto every Ethernet frame so a single cable can carry traffic from many [[VLAN]]s without the switches losing track of whose frame belongs to whom.

**802.1Q** is the IEEE standard that inserts a 4-byte VLAN tag into Ethernet frames so a single physical link — a **trunk** — can carry traffic for multiple VLANs while preserving each frame's VLAN membership end-to-end.

Without the tag, every frame looks identical the moment it leaves the switch. The receiving switch would have no idea whether a frame came from Sales, Engineering, or the printer VLAN — and would either flood it everywhere or drop it. The tag is the colored ghost suit that survives the trip across the wire.

## Why it matters

Without trunking, every VLAN needs its own physical cable between switches — a wiring closet from a horror game. Trunking collapses that into one link, but it also opens the door to **VLAN hopping** attacks if the [[native VLAN]] is misconfigured. On the exam, expect questions on tag structure, native VLAN behavior, [[router-on-a-stick]] configuration, and the allowed VLAN list — all four show up routinely.

## Key facts

### The 4-byte tag

Inserted between the Source MAC and the EtherType/Length field. Total frame grows by 4 bytes (max becomes 1522).

| Field | Size | Purpose |
|---|---|---|
| **TPID** (Tag Protocol Identifier) | 16 bits | Always `0x8100` — marks the frame as 802.1Q-tagged |
| **PCP** (Priority Code Point) | 3 bits | [[Class of Service]] / QoS priority, 0–7 (used by [[802.1p]]) |
| **DEI** (Drop Eligible Indicator) | 1 bit | Formerly CFI; 1 = drop me first under congestion |
| **VID** (VLAN Identifier) | 12 bits | The VLAN number, 0–4095 |

### VLAN ID ranges

- **0** — reserved (priority-tagged, no VLAN)
- **1–1005** — normal range; **1, 1002–1005** are reserved by Cisco
- **1006–4094** — extended range
- **4095** — reserved
- **Usable: 1–4094**

### Native VLAN

Frames on the [[native VLAN]] traverse a trunk **untagged**. Default is **VLAN 1**. Both ends of a trunk must agree, or [[CDP]] screams at you and traffic leaks between VLANs.

```
interface GigabitEthernet0/1
 switchport mode trunk
 switchport trunk encapsulation dot1q
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,30,99
```

### Double-tagging attack

The attacker sits on the native VLAN and sends a frame with **two** 802.1Q tags. The first switch strips the outer (native) tag and forwards the frame; the next switch reads the inner tag and delivers it to a VLAN the attacker shouldn't reach. One-way attack, but enough to be nasty.

**Mitigations:**
- Set native VLAN to an unused VLAN ID (never VLAN 1)
- Force tagging of the native VLAN: `vlan dot1q tag native` (global)
- Don't put user ports in the native VLAN

### Router-on-a-stick

One router interface, multiple [[subinterface]]s, one trunk to a switch. The router does inter-VLAN routing on a single physical link.

```
interface GigabitEthernet0/0
 no shutdown
!
interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
!
interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
!
interface GigabitEthernet0/0.99
 encapsulation dot1Q 99 native
 ip address 192.168.99.1 255.255.255.0
```

The `native` keyword tells the subinterface to handle untagged frames — match this to the switch's native VLAN.

### Allowed VLAN list

By default a trunk carries **all VLANs (1–4094)**. Trim it for security and broadcast hygiene:

```
switchport trunk allowed vlan 10,20,30
switchport trunk allowed vlan add 40
switchport trunk allowed vlan remove 20
switchport trunk allowed vlan except 100
switchport trunk allowed vlan all
```

Verify with `show interfaces trunk`.

### 802.1Q vs ISL

| Feature | **802.1Q** | **ISL** (Inter-Switch Link) |
|---|---|---|
| Origin | IEEE open standard | Cisco proprietary |
| Method | Inserts tag inside frame | Encapsulates entire frame (26-byte header + 4-byte trailer) |
| Frame size impact | +4 bytes | +30 bytes |
| Native VLAN | Yes (untagged) | No — tags everything |
| VLAN range | 0–4095 | 1–1000 |
| Status | Universal | Deprecated; modern Cisco switches don't support it |

If a switch only supports `dot1q`, the `switchport trunk encapsulation` command is hidden — there's nothing to choose.

### Verification commands

```
show interfaces trunk
show interfaces gi0/1 switchport
show vlan brief
show dtp interface gi0/1
```
