# IPv4 Addressing

## What it is

Every player in an online lobby needs a callsign so the server knows where to send the bullets. IPv4 addresses are exactly that for the internet — a 32-bit logical identifier that lives at Layer 3 and tells routers "this is me, send packets here."

The address is split into four 8-bit chunks called octets, written in dotted-decimal like `192.168.1.10`. Each octet ranges from 0 to 255 because 8 bits maxes out at 255 (binary `11111111`). Under the hood it's just a 32-bit binary string — humans see `192.168.1.10`, the router sees `11000000.10101000.00000001.00001010`.

Every IPv4 address has two parts glued together:
- **Network portion** — the "which Discord server are you in" part. Everyone on the same subnet shares this.
- **Host portion** — the "which user in that server" part. Unique per device.

The split between the two isn't visible from the address alone. You need a **subnet mask** to draw the line. The mask is another 32-bit value: a run of contiguous 1s (network bits) followed by a run of contiguous 0s (host bits). Non-contiguous masks like `255.0.255.0` are invalid — the 1s and 0s cannot be interleaved.

The **prefix length** (`/24`, `/16`, etc.) is just shorthand for "how many leading 1s are in the mask."

| Prefix | Mask | Host bits | Usable hosts |
|--------|------|-----------|--------------|
| /8 | 255.0.0.0 | 24 | 16,777,214 |
| /16 | 255.255.0.0 | 16 | 65,534 |
| /24 | 255.255.255.0 | 8 | 254 |
| /30 | 255.255.255.252 | 2 | 2 |

## Why it matters

Without IP addressing, routing doesn't exist. MAC addresses get you across one switch (one LAN party); IP addresses get you across the internet (matchmaking across regions). The network/host split is what lets routers make decisions on entire subnets at a time instead of memorizing every device on the planet — like how Steam routes you to a regional server cluster, not to one specific PC.

Get the mask wrong and your laptop will think the printer is on Mars. ARP fails, traffic gets shoved to the default gateway for no reason, and packets vanish into the void. Subnetting fluency isn't optional — it's the difference between a network that works and a Tuesday-night outage.

## Key facts

### Network and broadcast addresses
- **Network address** — all host bits set to 0. The "lobby name." Cannot be assigned to a device.
- **Broadcast address** — all host bits set to 1. The "@everyone ping" of the subnet. Also cannot be assigned to a device.
- That's why the formula is `2^host_bits − 2`. Two addresses are reserved before anyone gets one.
- First usable host = network address + 1. Last usable host = broadcast − 1.
- Example: `10.0.0.0/24` → network `10.0.0.0`, broadcast `10.0.0.255`, usable range `10.0.0.1` through `10.0.0.254`.
- Routers do **not** forward broadcasts. Broadcasts stay inside their subnet — like local voice chat in Helldivers 2 not reaching the next squad.

### Address classes (legacy, but still tested)
Old-school classful addressing carved up the address space by the leading bits:
- **Class A** — first bit `0`, first octet 1–126, default `/8`
- **Class B** — first bits `10`, first octet 128–191, default `/16`
- **Class C** — first bits `110`, first octet 192–223, default `/24`
- **Class D** — first bits `1110`, first octet 224–239, multicast (think Twitch stream — one source, many subscribed receivers)
- **Class E** — first bits `1111`, first octet 240–255, experimental

Classful addressing is **obsolete**. Modern routing uses **CIDR** (Classless Inter-Domain Routing), where the prefix length is explicit and doesn't have to follow class boundaries.

### Reserved ranges
- `0.0.0.0/8` — special use ("any address" / unspecified)
- `127.0.0.0/8` — loopback range. `127.0.0.1` is your machine talking to itself, the equivalent of testing your mic by talking into your own headset.

### Binary basics
- Binary is base 2, decimal is base 10.
- Octet place values, right to left: `1, 2, 4, 8, 16, 32, 64, 128`.
- `10001111` = 128 + 8 + 4 + 2 + 1 = **143**.

### IPv4 header
The header is the metadata wrapped around every packet — the loadout screen before the payload drops in.
- **Size**: 20–60 bytes, **14 fields**.
- **Version**: always `4` for IPv4.
- **IHL** (Internet Header Length): header size in 4-byte words. Minimum value `5` → minimum header `20 bytes`.
- **DSCP / ECN**: QoS tags. Tells routers "this is voice traffic, prioritize it" — like party chat getting bandwidth priority over a background download.
- **Total Length**: header + payload size.
- **TTL** (Time To Live): decremented by 1 at every router hop. At 0, the packet dies. Prevents routing loops from melting the internet — same reason Elden Ring caps how many summons can stack.
- **Protocol**: identifies the payload.
  - ICMP = 1
  - TCP = 6
  - UDP = 17
  - OSPF = 89
- **Header Checksum**: error-checks the header only, not the payload.
- **Source / Destination IP**: sender and receiver.
- **Options**: rarely used, basically dead weight.

### Routers and IP interfaces
Routers operate at Layer 3. Each router interface lives in **its own distinct subnet** — one interface per network, like one portal per region in a hub world.

- Cisco router interfaces are **shutdown by default** — administratively disabled out of the box.
- `no shutdown` brings the interface up.
- `show ip interface brief` — quick status table: interface, IP, status, protocol.
- `show ip interface g0/0` — detailed view including IP, prefix, broadcast address, and **MTU** (default `1500 bytes`).

**Interface status decoded** (status / protocol):
- `administratively down / down` — manually disabled, you forgot `no shutdown`
- `down / down` — no physical link, cable unplugged or other side dead
- `up / down` — physical link present (Layer 1 OK), but Layer 2 is broken (encapsulation mismatch, keepalive failure)
- `up / up` — fully functional, can carry data. The only state that actually works.

### Saving config
Running-config lives in RAM and dies on reboot — like an unsaved Minecraft world. To persist it to startup-config (NVRAM):
- `write`
- `write memory`
- `copy running-config startup-config`

All three do the same thing.
